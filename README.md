# en-words

自用的英语词块训练工具，目标是英文技术面试、和英文同事协作、读懂技术书。

| 文档 | 内容 |
|---|---|
| [docs/design.md](docs/design.md) | 方案设计和分期 |
| [docs/HANDOFF.md](docs/HANDOFF.md) | 给接手开发的人或 AI：现状、架构、规则、容易踩的坑 |
| [docs/ROADMAP.md](docs/ROADMAP.md) | 接下来做什么 |

当前做到 M3：

- **复习和新学**：双向间隔重复、新学小测、词库、朗读、导入导出
- **口语练习**：面试题限时口答、录音回听、自评、同题重答
- **场景对话**：站会、评审、1:1、事故、闲聊等职场对话的逐轮练习
- **模板**：STAR 故事卡、系统设计讲解框架
- **阅读助手**：粘贴英文，看认识的词占多大比例，点词看释义、收进生词本
- **词汇**：词汇量测评、按词频分段筛查、生词本
- **统计**：复习量预测、学习时长、各分类进度

## 使用

```bash
npm install
```

```bash
npm run dev
```

然后打开 http://localhost:5310。

学习记录存在浏览器的 IndexedDB 里，按“地址 + 端口”隔离。所以请固定用同一个浏览器和这个地址；换浏览器、换电脑或清理浏览器数据之前，先在“设置”里导出备份。备份里不含口答录音。

朗读用的是浏览器自带的语音。Edge 的 Natural 英文语音最自然，推荐用 Edge。口语练习第一次录音时，浏览器会请求麦克风权限；不给权限也能练，只是不能回听。

## 每天怎么练

1. **复习**：先做中译英（开口说），再做认读。说完按空格看答案，再按 1–4 自评。
2. **新学**：每组 5 条，听读音、跟读，看完马上小测，说错的当场重考。
3. **口语**：今日页每天推荐一道面试题。答两遍：第一遍 2 分钟，回听并对照提纲；第二遍限时 90 秒。题目页还会带出你已经学过的相关表达，答题时试着一起用上。
4. **场景**：有时间再练一个场景对话。
5. **阅读**：读技术书或文档时，把读的那一节粘贴进阅读助手，把反复出现的生词收进生词本。

第一次用建议先到“词汇”页做一次测评（约 10 分钟）。测评结果决定阅读助手默认把哪些词当作认识的；没测评时默认你认识最常用的 3000 个词。

生词本里的词会和其他新内容一起按组学习：每 4 组新内容里有 1 组来自生词本。词频排名 3000 以内的词练到说得出，其余的书面词只练认读。

| 复习自评 | 标准 |
|---|---|
| 1 忘了 | 没说出来，或者说错 |
| 2 困难 | 说对了，但超时或有停顿 |
| 3 记得 | 时限内说对 |
| 4 很熟 | 脱口而出 |

中译英的题目会随记忆变牢自动变难：提示回忆（5 秒）→ 整句翻译（10 秒）→ 情境应答（15 秒）。

口答时卡住的表达先用中文记下来，查到英文说法后填进去，它会成为你自己的词条并进入复习。面试题和场景里出现的表达，也可以点“加入复习”。

## 快捷键

| 页面 | 键 | 作用 |
|---|---|---|
| 复习、新学 | 空格 / 回车 | 看答案；新学时是下一条 |
| 复习 | 1–4 | 自评（“再练一遍”里 1 是没说对，2 是说对了） |
| 新学 | K | 标记“已经会了” |
| 新学小测 | 1 / 2 | 没说对 / 说对了 |
| 复习 | R / Z | 再听一遍 / 撤销上一次评分 |
| 口语 | 空格 | 开始回答；说完了 |
| 场景 | 空格 | 下一句；轮到你时是看参考说法 |
| 场景 | R / T | 再听一遍 / 看同事这句话的原文 |
| 场景 | 1 / 2 | 没说出来 / 说出来了 |
| 测评、筛查 | 1 / 2 | 不认识 / 认识 |
| 测评、筛查 | 空格 | 看完释义后下一个（测评里按 1 是“其实记错了”） |

## 加内容

- 零散的词：在“词库”里点“添加词条”。
- 批量：在“设置”里导入 CSV，列的顺序是 `英文, 中文提示, 例句英文, 例句中文, 层`。
- 内置词库：按 [content/README.md](content/README.md) 的规范在 `content/entries/` 下加 JSON 文件。
- 面试题和场景：按 [content/SPEAKING.md](content/SPEAKING.md) 的规范在 `content/questions/` 和 `content/scenarios/` 下加 JSON 文件。

加完后运行校验：

```bash
npm run validate
```

## 词典数据

阅读助手和测评用的词频词典 `content/wordlists/frequency.json` 由开源词典 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 授权，Copyright (c) Linwei）生成，包含最常用的 3 万个词和约 790 个补充的技术词。需要重新生成时，把 ECDICT 的 `ecdict.csv` 放到 `data/raw/ecdict/` 下（这个目录不进版本管理），然后运行：

```bash
node scripts/build-wordlist.mjs data/raw/ecdict/ecdict.csv
```

词典的释义来自通用词典，部分技术词的释义是日常义项而不是技术义项（例如 *scalable*、*serialize*）。遇到这种情况，以词库里的词块为准。
